def drop_conv3x3_block(in_channels, out_channels, stride=1, padding=1, bias=False, dropout_prob=0.0):
    return nn.Sequential(
    nn.Conv2d(in_channels, out_channels, kernel_size=3, stride=stride, padding=padding, bias=bias),
    nn.BatchNorm2d(out_channels),
    nn.SiLU(inplace=True),
    nn.Dropout2d(p=dropout_prob) if dropout_prob > 0 else nn.Identity(),
    nn.Conv2d(out_channels, out_channels, kernel_size=3, stride=1, padding=1, bias=bias),
    nn.BatchNorm2d(out_channels),
    nn.SiLU(inplace=True)
    )
</block>

def forward(self, x: torch.Tensor, is_probing: bool=False) -> torch.Tensor:
    x_a = self.backbone_a(x)
    x_b = self.features(x)
    x_b = adaptive_pool_flatten(x_b)
    x_f = adaptive_pool_flatten(self.backbone_b(x))
    x_out = torch.cat([x_a, x_b, x_f], dim=1)
    if is_probing:
        return x_out
    return self.classifier(x_out)
</forward>

### Explanation:
In this implementation, I have used the `TorchVision` class for the backbone models. The `drop_conv3x3_block` function is used to construct the dropout-enabled convolution block. In the `Net` class's `__init__` function, two backbone models are initialized - 'mobilenet_v3_large' and 'squeezenet1_0' from `TorchVision`. The number of input channels are extracted from the input image shape. The `FractalUnit` is used as the feature extraction part with the number of columns as 4 and 3 respectively. The forward function follows the 'A_to_Fractal_plus_B' pattern. The output of the forward function is a concatenation of the outputs of the backbone models 'mobilenet_v3_large' and 'squeezenet1_0' with the output of the feature extraction part.
