def forward(self, x: torch.Tensor, is_probing: bool = False) -> torch.Tensor:
    x_a = self.backbone_a(x)
    x_a = self.features(x_a)
    x_b = adaptive_pool_flatten(self.backbone_b(x))
    x_f = adaptive_pool_flatten(x_a)
    return self.classifier(torch.cat([x_f, x_b], dim=1))

### Explanation:
The 'A_to_Fractal_to_B' pattern is implemented by first applying the backbone_a (MobilenetV3Small) followed by the FractalUnit feature blocks and then backbone_b (ShufflenetV2X2_0). The FractalUnit feature blocks are applied to the output of backbone_a and the output of backbone_b is applied directly. The outputs from these branches are concatenated and passed through a fully connected layer.

The drop_conv3x3_block function is a block that contains a 3x3 convolution, a BatchNorm, a SiLU (Sigmoid linear unit) activation, a Dropout and another 3x3 convolution.

The Net class's init function initializes two backbone networks (backbone_a and backbone_b) and two feature blocks (features). The input image spec is stored in _input_spec for dynamic sizing of the classifier. The classifier is then initialized with the output dimension of the forward pass. The GradScaler is initialized as well.

The forward function follows the implemented pattern: backbone_a is applied to the input, features are applied to the output of backbone_a and the output of backbone_b is applied directly. The outputs from these branches are concatenated and passed through a fully connected layer. The output of this function is the output of the network.
