    x = self.backbone_a(x)
    x = self.features(x)
    x = adaptive_pool_flatten(x)

### Notes
The architecture of the model follows the target pattern A_to_Fractal_plus_B. The backbones used are resnet50 and efficientnet_b1. The FractalUnit consists of FractalBlock, which is a series of blocks with different depths. The dropout probability is 0.3 for the FractalBlock and 0.1 for the FractalUnit. The model uses adaptive average pooling for feature extraction. The model also uses mixed precision training if the use_amp hyperparameter is set to True.
