def forward(self, x: torch.Tensor, is_probing: bool = False) -> torch.Tensor:
    x_a = self.backbone_a(x)
    x_b = self.features(x)
    x_f = adaptive_pool_flatten(x_b)
    x_a = adaptive_pool_flatten(x_a)
    return self.classifier(torch.cat([x_a, x_f], dim=1))

### Explanation:
This model follows the pattern `Fractal_to_DualBackbone`. It starts with two backbone networks (`backbone_a` and `backbone_b`) that are selected from the torchvision models. The backbones are followed by a FractalUnit that consists of FractalBlocks. The output of `backbone_a` is concatenated with the output of `FractalUnit` before passing through a fully connected layer for classification. The `FractalUnit` has two FractalBlocks for each column. The FractalBlock consists of several 3x3 convolutions with dropout. The output of the model is a vector of size equal to the number of classes.

In the `__init__` function, the number of input channels is extracted from the input shape. The `infer_dimensions_dynamically` function is called to infer the dimension of the output of the model. The `forward` function implements the `Fractal_to_DualBackbone` pattern by concatenating the output of `backbone_a` and `FractalUnit` before passing it through a fully connected layer.

The model uses automatic mixed precision (AMP) for training if 'use_amp' is True in the parameter dictionary.

The model's forward pass can be used for inference (without dropout) by setting `is_probing` to `True`.
